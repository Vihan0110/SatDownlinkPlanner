How the planner works

Three steps in the current simulation.

01 / PRIORITISE

Order packets

Python packet classes assign priority, so important telemetry is considered before lower-priority data.

02 / CHECK

Respect link and time

The simulation checks each packet's minimum signal requirement and transmission time within a 60-second pass.

03 / RECORD

Save the outcome

Packet decisions and pass summaries are stored in SQLite and displayed here when the report is built.
